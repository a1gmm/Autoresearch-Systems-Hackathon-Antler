## CUPA Agency

**Lake County Division of Environmental Health** (Health Services Department)
255 N Forbes Street, Lakeport, CA 95453
Phone: 707-263-1164

Single CUPA for the entire county — covers both incorporated cities (Clearlake and Lakeport) as well as all unincorporated communities. No city-run CUPAs or participating agencies (PAs).

## Programs Administered

| Program | Authority |
|---------|-----------|
| Hazardous Waste Generator Permitting & Inspection | Cal. H&S Code div. 20 |
| Hazardous Waste On-Site Treatment Oversight | Cal. H&S Code div. 20 |
| Hazardous Materials Business Plans (HMBP) | Cal. H&S Code §25500 et seq. |
| Aboveground Petroleum Storage Act (APSA/AST) | Cal. H&S Code §25270 et seq. |
| Underground Storage Tanks (UST) | Cal. H&S Code §25280 et seq. |
| Treated Wood Waste (TWW) | Cal. H&S Code §25143.1.5 |
| CalARP (Risk Management Plan) | Cal. H&S Code §25531 et seq. |

Annual reporting via **CERS** (California Environmental Reporting System) required for HMBP and AST annual certification.

## Fee Authority

**Master Fee Ordinance 3056**, approved by Board of Supervisors on February 7, 2017. A 5% rate increase became effective July 1, 2022. The current schedule is effective **July 1, 2025** (Lake County Master Fee, Cost Recovery Schedule — "Master-Fee-FINAL-Eff-07012025").

## Notes

- State surcharges on UST permits "may be implemented at any time" and are in addition to county fees.
- Penalty for beginning construction on a UST (including associated piping) without a permit: **double fee**.
- Penalty for removing a UST without a Tank Abandonment Clearance: **double fee**.
- Penalty for operating a UST without a permit: **double fee**.
