## Adopted Code Edition

- **Current**: 2025 California Fire Code (CFC), based on the 2024 International Fire Code (IFC) with California amendments — effective **2026-01-01**, replacing the 2022 CFC.
- **Prior cycle**: 2022 California Fire Code (2021 IFC base), adopted by City Council; governed projects through 2025-12-31.
- Municipal code location: **FMC Chapter 10, Article 5 — Fire Prevention**.
- Building code companion: **FMC Chapter 11, Article 1** adopts the California Building Standards Code.

## Local Amendments (Known)

- **ERRC Radio Coverage**: Ord. ID 24-723 (City Council adopted 6/13/2024) amended FMC Ch. 10, Art. 5 to align ERRC system installation requirements with the 2022 CBSC's new referenced standard. FFD requires a permit prior to installation of all ERRC systems.
- FMC §10-55602 — Fireworks ordinance (local prohibition/regulation of fireworks within city limits; administrative fines effective May 19, 2022: 1st offense $2,000 + $250 State Marshall disposal fee; 2nd offense within 12 months $3,000 + $250; 3rd/subsequent $5,000 + $250).

## Special Hazard User Permits (Hazmat Storage)

Issued by FFD under CFC Chapter 1, Table 105.6.20. Required when hazmat quantities exceed specified thresholds.

| Level | Representative Triggers | Fee (FY2024) |
|-------|------------------------|--------------|
| Level 1 | 10–100 gal flammable/combustible liquid; 20–100 lb flammable solid; 201–3,000 cf compressed gas (excl. CO2/LPG); aerosols L2/L3 50–999 lb; high-piled storage 501–2,500 sf; LPG 250–1,149 gal; tires indoors (any amount); combustible dust equipment; repair garage | $129 |
| Level 2 | 101–1,000 gal flammable/combustible liquid; 101–1,000 lb flammable solid; 3,000–6,000 cf compressed gas; aerosols L2/L3 1,000–2,400 lb; high-piled storage 2,501–12,000 sf; CO2 12,000–18,000 cf; LPG 1,150–2,299 gal | $145 |
| Level 3 | >1,000 gal flammable/combustible liquid; >1,000 lb flammable solid; >6,000 cf compressed gas; aerosols L2/L3 ≥2,500 lb; high-piled storage ≥12,001 sf; CO2 ≥18,000 cf; LPG ≥2,300 gal | $202 |
