## CUPA Agency

**Sutter County Environmental Health Division** (within the Development Services Department) is the CalEPA-certified CUPA for the **entire county, including the incorporated cities of Yuba City and Live Oak**. There are no city-run CUPAs and no participating agencies — Sutter County is a single-agency CUPA.

## Programs Administered

The CUPA administers all six unified program elements:

1. **HMBP** — Hazardous Materials Business Plan (CA Health & Safety Code §25500 et seq.)
2. **Hazardous Waste Generator** program (including onsite treatment)
3. **UST** — Underground Storage Tank program
4. **AST / APSA** — Aboveground Petroleum Storage Act (tanks ≥ 1,320 gallons)
5. **CalARP** — California Accidental Release Prevention program (RMP equivalent)
6. **Tiered Permitting** (hazardous waste onsite treatment)

Effective January 2013, all regulated businesses must submit HMBP data electronically through the California Environmental Reporting System (CERS) per AB 2286.

## Governing Ordinance / Code Chapter

**Chapter 770 — Regulations Pertaining to the Certified Unified Program Agency**, Title 700 (Health and Sanitation) of the Sutter County Code of Ordinances. Chapter 770 derives authority from California Health and Safety Code §25404 (Chapter 6.11) and California Code of Regulations, Title 27, Division 1, Subdivision 4, Chapter 1, Section 15100.

## HazMat Emergency Response

The **Yuba-Sutter Hazardous Materials Response Team (YSHMRT)** provides regional HazMat emergency response drawing from Yuba City, Marysville, Linda, Wheatland, Olivehurst, Beale AFB, and Yuba and Sutter Counties. This is mutual-aid *response* — it is separate from CUPA administration and permitting.
