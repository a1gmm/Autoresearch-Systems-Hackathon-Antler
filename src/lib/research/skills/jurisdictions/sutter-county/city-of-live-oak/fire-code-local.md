## Live Oak City-Adopted Fire Code

The City of Live Oak adopts the California Fire Code by ordinance at each code cycle. The most recent confirmed adoption is:

- **Adopted code:** 2025 California Fire Code (Title 24, Part 9)
- **Adopting ordinance:** Ordinance No. 589 (City of Live Oak City Council)
- **Municipal code location:** Chapter 8.08 (Fire Prevention), Live Oak Municipal Code — https://ecode360.com/43403041
- **Platform:** eCode360 (https://ecode360.com/LI4959)

Ordinance No. 589 also simultaneously adopted the 2025 California Administrative Code, Building Code, Residential Code, Electrical Code, Mechanical Code, Plumbing Code, Energy Code, Wildland-Urban Interface Code, Historical Building Code, Existing Building Code, Green Building Standards Code, and Referenced Standards Code as a package adoption.

## Chapter 8.08 Local Content (from search index)

Chapter 8.08 of the Live Oak Municipal Code covers at minimum:

- Open burning / bonfires and outdoor rubbish fire restrictions
- Dry and combustible materials near buildings (Health & Safety Code Part 5, Division 12 incorporated)
- Fire hydrant usage restrictions
- Abatement of fire hazards authority

## Fire Permits

Fire prevention operational permits (for hazardous materials storage, compressed gas, high-piled storage, etc.) are issued by the Sutter County Fire Department as the operational AHJ. Contact (530) 822-7400 for permit requirements.
