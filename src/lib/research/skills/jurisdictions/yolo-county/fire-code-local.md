> This file covers fire code adoption and the AHJ structure for the **unincorporated** Yolo County area only.
> The four incorporated cities (Davis, Woodland, West Sacramento, Winters) each have their own municipal fire departments and adopt the CFC under their own ordinances — see city-level files.

## Adopted Fire Code

- **Code name:** Fire Code of Yolo County
- **Governing chapter:** Yolo County Code **Title 7 (Building Regulations), Chapter 1 (California Codes and Local Amendments Thereto)**
  - **Sec. 7-1.02** — Adoption of Codes (adopts the California Fire Code by reference)
  - **Sec. 7-1.11** — Amendments to the California Fire Code (local amendments)
- **Edition last confirmed in code text:** 2019 California Fire Code (CFC), Title 24 Part 9 CCR, including Appendix Chapters B, C, D, E, F, G, and H — as reflected in the current amlegal codification.
- **Edition status [VERIFY]:** The amlegal code library is current through **Ordinance 1582** (effective 2026-01-01 / 2026-01-08). The **2025 California Fire Code** (Title 24 Part 9, 2025 Edition) became the statewide baseline on 2026-01-01. Whether Yolo County adopted the 2022 or 2025 CFC via Ordinance 1582 or a prior ordinance could **not** be confirmed from any fetchable source — amlegal pages return HTTP 403 to automated fetch. Confirm the operative local edition before quoting.

## Local Amendments (Sec. 7-1.11)

From search-indexed excerpts of Sec. 7-1.11:
- **CFC Chapter 1 — Scope and Application, Division II (Administration) is amended** by the county.
- Title of the regulations is changed to "Fire Code of Yolo County."
- Conflict rule: where conflicts occur between provisions of the Fire Code of Yolo County and referenced codes/standards, county provisions control; where conflicts occur between county fire code administrative provisions and CBC Chapter 1, the more specific provision controls.

## Fire AHJ — Unincorporated Area

There is **no unified county fire department** for the unincorporated Yolo County area. Fire code authority (AHJ) is distributed across **15 independent fire protection districts**, each with its own board and service territory:

- **Implication for EHS research:** For any specific unincorporated facility, identify which FPD has jurisdiction over that parcel (consult the Yolo LAFCo district boundary maps or the county's special district directory). The applicable FPD is the fire AHJ and issues CFC operational permits, conducts inspections, and coordinates with the county Building Inspection Services on plan check.
- Each FPD independently adopts the California Fire Code (typically tracking the statewide cycle). **[VERIFY]** individual FPD adoption ordinances are not published online for most of these small volunteer/rural districts.

## Key Gotchas

- **No county fire department / no single AHJ:** there are 15 separate FPDs; identify the correct one by parcel location before any permit inquiry.
- **Adopted CFC edition unconfirmed:** the search-indexed code text references 2019 CFC, but Ordinance 1582 (effective 2026-01-01) may have updated this — [VERIFY live].
- **City facilities:** Davis FD, Woodland FD, West Sacramento FD, and Winters FD are the AHJ for their respective city limits — those are not covered here.
