> Local fire code reference for Tehama County (unincorporated). The two largest cities —
> Red Bluff and Corning — operate their own fire departments and are separate AHJs.
> Verify the currently effective code edition with the Building & Safety Department, as
> Ordinance #2150 adopted the 2025 code cycle effective 2026-01-01 statewide.

## Adopted Fire Code — Unincorporated Tehama County

- **Adopted code:** California Fire Code (CFC), Title 24, Part 9, California Code of
  Regulations — **2022 Edition** (incorporating the International Fire Code, 2018 Edition
  with California amendments).
- **Adopting ordinance:** Ordinance #2127 (Code Cycle 2022 adoption). Ordinance #2150
  adopted the 2025 Code Cycle for building and construction codes; confirm whether the
  2025 CFC is simultaneously in effect [VERIFY — the Building & Safety page lists Ord.
  #2150 for "Code Cycle 2025" but does not itemize whether the fire code chapter was
  re-adopted under that same ordinance].
- **Municipal Code chapter:** Chapter 15.34 — FIRE CODE (Tehama County Code Title 15,
  Buildings and Construction).
- **Fire Board of Appeals:** Chapter 15.34.040 establishes the Fire Board of Appeals
  process for appeals of fire code official decisions.
- **Fire Safe Regulations:** Chapter 9.14 establishes Fire Safe Regulations (defensible
  space, vegetation management) applicable in State Responsibility Areas within the county.
- **Fire Benefit Zone:** Chapter 9.13 — Tehama County Fire Benefit Zone One (funding
  mechanism for rural fire services).

## Fire Authorities Having Jurisdiction (AHJ)

### Unincorporated Tehama County

- **AHJ:** CAL FIRE / Tehama County Fire Department (Tehama-Glenn Unit, TGU)
- CAL FIRE and Tehama County Fire operate under a cooperative agreement in place
  since 1927; CAL FIRE TGU personnel serve as the county fire authority.
- **Service area:** All unincorporated territory, including State Responsibility Area (SRA)
  and Local Responsibility Area (LRA) outside city limits.
- **Web:** https://www.tehamacountyfire.org/
- CAL FIRE TGU contact: Red Bluff Emergency Command Center, Red Bluff, CA

### City of Red Bluff (separate AHJ — not Tehama County Fire)

- **AHJ:** Red Bluff Fire Department (independent municipal combination career/reserve)
- **Address:** 555 Washington Street, Red Bluff, CA 96080
- **Web:** https://www.rbfd.org/
- Red Bluff adopted its own fire code locally — see city-of-red-bluff subfolder.

### City of Corning (separate AHJ — not Tehama County Fire)

- **AHJ:** Corning Volunteer Fire Department (all-volunteer, dispatched by City of Corning)
- **Web:** https://www.corning.org/departments/fire-department/
- Corning maintains its own fire code authority — see city-of-corning subfolder.
