## Programs Administered

Under California Health and Safety Code § 25404, the Butte County CUPA consolidates six state programs:

1. **Hazardous Materials Release Response Plan (HMRRP) / Business Plan** — contingency planning and emergency response for facilities storing hazardous materials above threshold quantities
2. **Hazardous Waste Generator Program** — oversight of CESQG, SQG, and LQG generators; governed by California Code of Regulations Title 22
3. **Underground Storage Tank (UST) Program** — installation, operation, repair, closure permits
4. **Aboveground Petroleum Storage Act (APSA)** — aboveground petroleum storage compliance
5. **California Accidental Release Prevention (CalARP)** — risk management prevention plans for regulated substances
6. **On-Site Hazardous Waste Treatment** — conditionally exempt, conditionally authorized, and permit-by-rule tiers

Enforcement approach: education, community/industry outreach, inspections, and enforcement actions.

Source: https://www.buttecounty.net/764/CUPA | https://www.buttecounty.net/825/Hazardous-Waste-Program

## Local Hazmat Ordinance

- **No Chico-specific local hazmat ordinance** identified — all programs operate under state statutes (H&S Code §§ 25400–25411.3 for CUPA, § 25270 for APSA, § 25531 for CalARP) and Butte County fee authority (County Code § 3-331).
- Butte County fee authority: **Butte County Code Section 43-6** (CUPA Fees).

## Application Process

- Applications submitted by email to **bcenvhealth@buttecounty.net** or via forms available at https://www.buttecounty.net/816/Hazmat-CUPA
- Forms available in DOC and PDF: permit applications for all program types, fee worksheets, financial responsibility exhibits, inspection logs, reporting forms, response plans, closure certifications
- State Unified Program reporting is conducted via **CERS** (California Environmental Reporting System) at https://cers.calepa.ca.gov/
