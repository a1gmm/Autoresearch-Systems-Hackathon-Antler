## Adopted Fire Code Edition

**Currently adopted:** 2025 California Fire Code (Title 24, Part 9), effective January 1, 2026 per the California 2025 code cycle.

**Previously adopted (prior cycle):** 2022 California Fire Code (Title 24, Part 9), effective January 1, 2023. City of Riverside informational bulletins (e.g., Bulletin 2022-014, 2022-034) carry the header "APPROVED BY: C. Kodat, Fire Marshal, 1/1/2023" confirming January 2023 as the effective date for that cycle.

The City also adopts in parallel:
- NFPA standards (as referenced in operational bulletins)
- Title 19 of the California Public Safety Code
- California Health and Safety Code

## Municipal Code Location

**Title 16 — Buildings and Construction, Chapter 16.32 — Fire Prevention**
(Riverside Municipal Code, codified through Ord. No. 7757, March 10, 2026)

Chapter 16.32 is the adopting chapter for the California Fire Code within the City's municipal code. Additional fire-related chapters within Title 16 include:
- **Chapter 16.36** — Public Safety Radio Amplification Systems (local amendment adding in-building RF coverage requirements beyond base CFC Section 510; references NFPA 1221-2019 Edition)

## Operational Permits Required (Non-Exhaustive)

Per the 2025/2022 CFC as adopted and RMC Chapter 16.32:

| Permit Type | Threshold / Notes |
|-------------|-------------------|
| Hazardous Materials (CFC Ch. 50+) | Reportable quantities: ≥55 gal liquid, ≥500 lb solid, ≥200 cu ft compressed gas (lower for acutely/extremely hazardous) |
| High-Piled Storage | Application + signage/design required; form available on city forms page |
| Aboveground Petroleum Storage (APSA) | Administered through HMBP/Participating Agency program; APSA tiers I–III |
| Spray Booths, Blasting | Separate permit applications |
| Fireworks Public Display | Separate permit application |
| Special Events | Special Event Request Application |
| Public Safety Radio Amplification | Required per RMC Ch. 16.36 for applicable new/renovated buildings |

## Local Amendments — Confirmed

1. **RMC Chapter 16.36** (Public Safety Radio Amplification Systems): Requires in-building RF coverage meeting signal strength thresholds in ≥95% of all areas and ≥99% of critical areas on each floor. References 2022 CFC Section 510 and NFPA 1221-2019. Standby power minimum 12-hour capacity. Annual testing required. Testing fees apply at plan submittal. *(Source: Fire Department Informational Bulletin 2022-014)*

2. **Open Burning / Bonfires**: Ordinance No. 2025-001 addresses open burning, bonfires, and portable outdoor fireplaces as a local amendment. *(Source: Forms & Resources page)*

## Fee Schedule

No public fee schedule is posted online. The Fire Prevention Division charges fees for permit review and inspection; late penalties apply per city fee resolution: **20% after 60 days; additional 80% after 90 days**.

Contact Fire Prevention at (951) 826-5737 to confirm current fees before submittal.
