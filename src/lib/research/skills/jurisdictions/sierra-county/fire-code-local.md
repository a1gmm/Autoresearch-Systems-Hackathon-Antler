## Controlling Authority

Sierra County enforces Title 24, Part 9 (California Fire Code) through **Sierra County Code Chapter 12.04 — Building Code**. The county has no single countywide fire department; the AHJ for fire code enforcement varies by community (see below).

## Adopted Edition

- **California Fire Code (CFC) 2010 Edition** (Title 24, Part 9), which incorporates the International Fire Code (IFC) 2009 Edition as published by the International Code Council (ICC), as adopted and amended by the California Building Standards Commission. ## Authority Having Jurisdiction (AHJ)

There is no single countywide fire AHJ. AHJ assignment depends on location:

| Area | AHJ |
|---|---|
| Eastern unincorporated (Sierraville, Sattley, Calpine area; ~515 sq mi east of Sierra crest) | Sierra County Fire Protection District #1 (volunteer) |
| State Responsibility Area wildland protection | CAL FIRE — Nevada-Yuba-Placer Unit (NEU) |
| City of Loyalton (sole incorporated city) | Loyalton Volunteer Fire Department (city-run); see city file |
| Other unincorporated communities | Specific district assignments unverified — confirm by community |

For building permit / fire code plan review, the AHJ is the **Sierra County Building Inspection Division** (Department of Planning, Downieville; 530-289-3251) for unincorporated areas. The county enforces the 2022 California Building Code (as stated on the building page); fire code edition should be confirmed with the same office.
