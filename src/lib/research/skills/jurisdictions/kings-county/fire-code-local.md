## Adopting Ordinance and Municipal Code Chapter

- **Kings County Code of Ordinances, Chapter 10 — Fire Prevention and Protection**
- Adopting ordinance: **Ordinance 713** (cited in the Kings County County Code of Ordinances index at countyofkingsca.gov/services/county-code-of-ordinances-2034)
- Municode permalink: https://library.municode.com/ca/kings_county/codes/code_of_ordinances?nodeId=COOR_CH10FIPRPR
- Chapter 10 subpart identified in search: Article II — Aboveground/Well/Flammable Material (§ 10-38 et seq.)

**Adopted CFC edition: [VERIFY]** — The county website blocks automated access. The statewide 2022 California Fire Code (based on IFC 2021, effective Jan. 1, 2023) applied through Dec. 31, 2025; the 2025 California Fire Code (based on IFC 2024) took effect statewide Jan. 1, 2026. Confirm which edition Kings County has locally adopted via Municode or by calling the Fire Marshal at (559) 852-2885.

## Online Permit Portal

Kings County Fire Department now accepts digital applications and plan submittals through the Online Permit Center:
- **URL:** https://firepermits.countyofkings.com/
- Existing CDA permit portal credentials (cdapermits.countyofkings.com) carry over — same User ID and Password.
- An "application pre-check" feature is available for applicants uncertain about required submittals.
- Portal allows: submit permit applications, submit plans, view corrections, view permits ready for issuance.
