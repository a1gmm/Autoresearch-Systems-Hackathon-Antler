## Adopting Ordinance

**Ordinances:** No. 23-0008 and No. 2023-0058
**Effective date:** January 11, 2024
**Codified as:** Los Angeles County Code (LACC) **Title 32 — Fire Code**
**Based on:** 2022 California Fire Code (CFC 2022), which itself incorporates by reference the 2021 International Fire Code (IFC 2021).

> The previous Title 32 was based on the 2019 CFC; this adoption cycle is every three years per CA Health & Safety Code § 18942.

## Local Findings Basis

All amendments constituting more restrictive building standards are grounded in local climatic, geological, and/or topographical conditions (required findings tabulated at end of ordinance per CA H&S Code § 18941.5).

## Operational Permit Fees (Appendix QQ, Table QQ104.2 — effective 2024-01-11)

Most operational permits are a flat **$390.00 per permit**, including:
- Hazardous Materials
- Hazardous Production Materials (HPM) Facilities
- High-Piled Combustible Storage
- Compressed Gases
- Flammable or Combustible Liquids
- Automobile Wrecking Yard
- Explosives
- Spraying or Dipping
- Energy Storage Systems
- Refrigeration Equipment

**Mass-Gathering Event (5,000+ persons):** $780.00 per permit

## Plan Review Fees (Appendix QQ, Table QQ104.3)

Key hazmat/industrial categories (from fee schedule table of contents):
- Building plan review
- Hazardous materials review (1–50 chemicals): see Appendix QQ Table QQ104.3(4)
- Hazardous materials review (>50 chemicals): see Appendix QQ Table QQ104.3(4)
- High-piled combustible storage review: see Appendix QQ Table QQ104.3(4)
- Fire sprinkler plan review

Full fee schedule PDF: https://fire.lacounty.gov/wp-content/uploads/2025/10/2023-LACFC-Appendix-QQ-Certified-Ord-Eff.-2024-01-11-Secured.pdf

## Annual Inspection Fees (Appendix QQ, Table QQ104.5)

Covers hazardous occupancies, high-rise buildings, high-piled combustible storage, petroleum/chemical unit inspections. New annual inspections ($98–$3,122 range per BOS letter) added for FY 2023 cycle.
