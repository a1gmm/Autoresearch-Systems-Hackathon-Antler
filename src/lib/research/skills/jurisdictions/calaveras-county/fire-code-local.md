## Ebbetts Pass Fire District — CFC Enforcement Practice (Confirmed)

As a representative district, Ebbetts Pass Fire District (Arnold area) enforces:
- California Fire Code (edition [VERIFY])
- NFPA Life Safety Codes and Standards
- Ebbetts Pass Fire District Ordinances

Plan review scope: fire alarm systems, sprinkler systems, suppression systems, exits/egress, storage configurations, propane installations, new construction, and alterations.

Inspection frequency: commercial properties and residential buildings with 2+ units inspected per CFC mandate. FSEs (child home daycares, preschools, schools) inspected separately.

Fire investigations coordinated with County Fire Investigation Unit, State Fire Marshal, and Calaveras County Sheriff.

Source: https://www.epfd.org/inspections

## Notes for Research Subagent

- Always determine which fire district's boundaries cover the specific parcel before citing permit requirements or adopted code edition — each district is an independent AHJ.
- CAL FIRE TCU enforces CFC in SRA zones for construction plan review via the State Fire Marshal's office process.
- County Building Department (building.calaverasgov.us) handles building permits for unincorporated areas and coordinates fire code review with the appropriate district AHJ.
