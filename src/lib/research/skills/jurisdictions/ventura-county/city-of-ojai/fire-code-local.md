## Fire AHJ

The City of Ojai contracts with the **Ventura County Fire Department (VCFD)** for all fire services. VCFD is the Authority Having Jurisdiction (AHJ) for fire prevention, plan review, inspections, and permitting within city limits.

- Ojai City page: https://www.ojai.ca.gov/430/Ventura-County-Fire-Department
- VCFD Fire Prevention Bureau: fireprevention@venturacounty.gov / (805) 389-9738

## Adopted Fire Code

**VCFD Ordinance No. 34** — Ventura County Fire Code (VCFC) and Ventura County Wildland-Urban Interface Code (VCWUIC), **effective January 1, 2026**. This ordinance is based on the 2022 California Fire Code (CFC, Title 24, Part 9), with VCFD local amendments.

**Ojai local adoption — Ordinance No. 969** (adopted December 9, 2025): "Building Code Update." This is Ojai's most recent building/fire code adoption ordinance as of June 2026. ## Wildland-Urban Interface (WUI)

The Ojai Valley is designated **Very High Fire Hazard Severity Zone (VHFHSZ)**. WUI requirements of the VCWUIC (adopted by VCFD Ord. 34) apply to all new construction and significant remodels within city limits.

## Fire Prevention Bureau Permits (VCFD)

Permit types handled by VCFD Fire Prevention Bureau for Ojai facilities:

- Fire protection systems (sprinklers, alarms, cooking suppression hoods, private water systems)
- High-piled combustible storage (dedicated form required)
- Hazardous materials / operational fire code permits
- New structures and additions; State Fire Marshal-regulated occupancies (Groups A, E, I, R, H, L)
- Landscape and fuel modification zones
