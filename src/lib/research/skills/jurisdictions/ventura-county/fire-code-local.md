## Fire AHJ

- **Primary AHJ:** Ventura County Fire Protection District (VCFPD) — serves unincorporated Ventura County and most contract cities.
- **Exceptions:**
  - City of Oxnard — Oxnard Fire Department (own full AHJ)
  - City of Ventura (San Buenaventura) — Ventura City Fire Department (own AHJ within city limits)

## Adopted Fire Code Edition

- **Ventura County Fire Code (VCFC):** Adopted by **VCFPD Ordinance No. 34**, effective **January 1, 2026**.
  - Adopts the **2025 California Fire Code (CFC)** with Appendix Chapters D and P
  - Adopts portions of the **2024 International Fire Code (IFC)**
  - Adopts the **2025 California Wildland-Urban Interface Code (CWUIC)** with portions of the 2024 IWUIC
  - Adopts portions of **Title 19, California Code of Regulations** (State Fire Marshal regulations), per the Matrix Adoption Table for each CFC chapter
  - Includes local additions, deletions, and amendments
  - Repeals VCFPD Ordinances No. 29 and 32
- **Wildland-Urban Interface Zones:** VCFPD **Ordinance No. 33** (effective **July 1, 2025**) adopts 2025 Local Responsibility Area Fire Hazard Severity Zone Maps.

## Municipal Code Reference

- The VCFPD fire code is a district ordinance (not codified in the Ventura County Ordinance Code proper). It is published at the VCFPD website and incorporated by reference.
- The Ventura County Ordinance Code does contain fire-related provisions at **Division 5, Chapter 1 — Fire Protection** (Municode: `DIV5SA_CH1FIPR`), but the operative fire code adoption for unincorporated areas is the VCFPD district ordinance.

## Key Local Provisions in Ordinance 34

- Sellers of real property in High or Very High Fire Hazard Severity Zones must provide buyers with documentation proving compliance with defensible space requirements (AB 38 implementation, effective January 1, 2026).
- High-piled combustible storage permit: required form "High-Piled Combustible Storage" must accompany fire code permit application.
- All local additions, deletions, and amendments to the 2025 CFC are set forth in Ordinance 34.
