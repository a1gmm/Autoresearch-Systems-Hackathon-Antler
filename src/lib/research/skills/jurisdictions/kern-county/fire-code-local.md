## Adopted Code Edition

Kern County adopted the **California Fire Code (CFC), 2019 Edition** (California Code of Regulations Title 24, Part 9), together with the **International Fire Code, 2018 Edition** (including Appendices B, C, and D) published by the International Code Council — as modified and amended by Kern County Ordinance No. 8866.

- Adopting ordinance: **Ordinance No. 8866**, adopted **November 5, 2019**
- Municipal code chapter: **Chapter 17.32, Title 17** (Buildings and Construction) of the Kern County Ordinance Code
- AHJ for unincorporated county and contract cities: **Kern County Fire Department**, Fire Prevention Division
  - Phone: (661) 391-3310
  - Email: fireprevention@kerncountyfire.org
  - Source: https://kerncountyfire.org/fire-prevention/building-codes/

Note: The **City of Bakersfield** administers its own fire code under Bakersfield Municipal Code — see city-of-bakersfield/ subfolder.

## Required Operational Permits (§ 105.6 as amended)

Kern County Fire Code requires operational permits for:

1. Burning (agricultural waste — with Air District approval)
2. **Business Operating Permit** — all occupancies except R-2, R-3, R-3.1, and U (fee: $145)
3. Explosives or Blasting Agents (storage of any quantity)
4. Filming
5. Fireworks Booths (Safe & Sane)
6. High-Piled Combustible Storage — >500 sq ft (fee: $290)
7. Mobile Fueling (fee: $290)
8. Model Rocket Engines (sale)
9. Place of Assembly (≥50 attendees in non-assembly facility) (fee: $180)
10. Public Displays — fireworks/explosives (fee: $145)
11. Special Effects/Operations (fee: $290)
12. Cannabis Cultivation — commercial indoor (fee: $290; large >5,000 sf: $290 + $0.026/sf)
13. Plant Extraction System (fee: $145)
14. Carbon Dioxide Enrichment System (>100 lbs CO₂) (fee: $145)
15. Mobile Food Prep Vehicles (with grease/smoke appliances) (fee: $145)

## Wildland-Urban Interface

Chapter 17.34 of Title 17 adopts the **California Wildland-Urban Interface Code**. The hazardous fire area boundary follows California's Fire Hazard Severity Zone designations (Public Resources Code §§ 4201–4204; Government Code §§ 51175–51189).

## Violation Penalties

- Misdemeanor conviction: fine up to **$1,000** and/or county jail up to **6 months**
- Administrative penalty: per Kern County Ordinance Code § 8.54.060
- Each day of continued violation is a separate and distinct offense

Source: Kern County Ordinance No. 8866, § 17.32.026 and § 17.34.130
