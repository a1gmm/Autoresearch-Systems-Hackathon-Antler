## CUPA Agency

**Kern County Public Health Services Department, Environmental Health Division**
- Serves as CUPA for the **entire unincorporated county** and all incorporated cities **except the City of Bakersfield**
- City of Bakersfield operates its own CUPA — Bakersfield Fire Department, Fire Prevention Division, Environmental Services (certified since 1996)

### Contact
- Address: 2700 M Street, Suite 300, Bakersfield, CA 93301
- CUPA Program phone: **(661) 862-8740**

- Website: https://www.kernpublichealth.com/permitting-compliance/unified-program-agency-upa

### Certification
- Kern County Environmental Health Services Department certified as CUPA: **December 13–14, 2006** (per CalEPA evaluation records)

## Programs Administered

The Kern County CUPA administers all six Unified Program elements required by Health & Safety Code § 25404 for facilities in its jurisdiction:

| Program | State Authority |
|---|---|
| Hazardous Materials Business Plan (HMBP) | H&S Code Chapter 6.95 |
| Hazardous Waste Generator (HW) | H&S Code Chapter 6.5 |
| Underground Storage Tanks (UST) | H&S Code Chapter 6.7 |
| Aboveground Petroleum Storage Act (APSA) | H&S Code Chapter 6.67 |
| California Accidental Release Prevention (CalARP) | H&S Code Chapter 6.95, Art. 2 |
| Hazardous Materials Release Response Plans (HMRRP) | H&S Code Chapter 6.95 |

## Hazardous Materials Business Plan (HMBP)

- **Reporting system**: California Environmental Reporting System (CERS) — mandatory statewide web-based platform under AB 2286 (H&S Code § 25404 et seq.)
- CERS portal: https://cers.calepa.ca.gov/
- Threshold: Businesses storing hazardous materials above statutory thresholds must submit HMBP electronically via CERS
- Source: https://www.kernpublichealth.com/permitting-compliance/unified-program-agency-upa/hazardous-materials-business-plan-california-environmental-reporting-system-cers

## Underground Storage Tanks (UST)
