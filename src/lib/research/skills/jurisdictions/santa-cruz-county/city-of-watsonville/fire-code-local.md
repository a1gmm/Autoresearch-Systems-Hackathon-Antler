## Authority Having Jurisdiction (AHJ)

**City of Watsonville Fire Department** — municipal department; administers fire code enforcement and fire/life-safety inspections within city limits.

- Address: 372 Airport Boulevard, Watsonville, CA 95019
- Main: (831) 768-3200
- Non-emergency: (831) 471-1170
- Fire Prevention Bureau: (831) 768-3231

## Adopted Code

| Item | Detail |
|------|--------|
| Municipal Code location | WMC **Chapter 8-9** (Fire Code), within Title 8 (Building Regulations) |
| Adopted edition | **2022 California Fire Code** (based on IFC 2021) |
| Appendices adopted | B, BB, C, CC, I, and N |
| Code current through | Ordinance 1482-25 (CM), passed September 9, 2025 |

## Key Local Amendments

- **CFC Section 502.1** (bridge/access definitions) — amended locally.
- **CRC Section R313** (residential sprinklers) — **NOT adopted**; Chapter 9 of the City Fire Code applies instead for sprinkler requirements.
- NFPA 13, NFPA 13-D, and NFPA 13-R referenced for sprinkler design by occupancy type.
- Appendix C and §906 fire extinguisher provisions; §907 fire alarm provisions; §503.3 fire apparatus access.

## Plan Review Requirements

Construction documents for the following must be submitted to the Fire Department **prior to construction**:
- Fire apparatus access roads and fire lanes
- Fire hydrant placement and hydraulic calculations

Contact Fire Prevention at (831) 768-3231 for all inspection requests, annual fire/life-safety inspections, or fire code concerns on existing structures.
