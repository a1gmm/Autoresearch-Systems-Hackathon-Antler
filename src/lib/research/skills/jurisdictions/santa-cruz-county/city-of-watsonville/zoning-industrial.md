## Conditional Use Permit (CUP / Special Use Permit) Process

Certain industrial uses in both the IP and IG districts require a **Special Use Permit** (Watsonville's term for a Conditional Use Permit) before operation. As of Ordinance 1481-25 (effective October 9, 2025), the code distinguishes between:

- **Administrative Use Permit** — for lower-impact uses; staff-level approval.
- **Special Use Permit** — for uses requiring Planning Commission hearing.

The purpose of the Special Use Permit is to ensure proper integration of uses which, because of their special nature, may be suitable only in certain locations or zoning districts or only if arranged or designed in a particular manner.

Key process steps [VERIFY specific fees and timelines with CDD]:
1. Pre-application consultation with Planning Division.
2. Submit Special Use Permit application with site plan, project description, and application fee.
3. Environmental review under CEQA as applicable.
4. Planning Commission public hearing and decision.
5. Appeal to City Council if contested.
