## One-Line Decision Guide

1. **Does the equipment emit or may emit air contaminants?** → Yes → check Rule 401 exemptions.
2. **Is it exempt under Rule 401 Section 4?** (e.g., boiler <1 MMBtu/hr, ICE <50 hp, spray coating <1 qt/day, graphic arts <15 lb VOC/day + <300 lb/yr) → If yes, no ATC/PTO needed (keep records).
3. **If not exempt** → file ATC application under Rule 400 before construction; obtain PTO before operation.
4. **If PTE ≥ 100 tpy any nonattainment pollutant** → also triggers Rule 432 Federal NSR (BACT + offsets).
5. **Applying architectural coatings to structures?** → Categorically exempt from permit (Rule 401 §4.7.4); VOC content must comply with Rule 2.12(f) (≤250 g/L general, ≤350/450 g/L interior).

## Nonattainment Status (for NSR context)

Butte County is in **nonattainment** for 8-hour ozone and PM2.5 (Sacramento Valley Air Basin). NOx, VOC, and PM2.5 are the most closely tracked pollutants for new source review.

## Notes on District Rule Structure

Butte County AQMD is a relatively small district. It does not have stand-alone rules for many source categories (no dedicated automotive refinishing rule, no dedicated degreaser rule). The district's rules page (https://www.bcaqmd.org/district-rules) redirects to the CARB Air District Rule Database for the complete rule book. The district's own website hosts selected rule PDFs directly at `https://www.bcaqmd.org/files/`. The most comprehensive single source is the EPA-compiled SIP rules PDF linked above.
