# Mariposa County APCD — Skill Index

## District Profile

Mariposa County APCD is a small, rural district in the Sierra Nevada foothills (Mountain Counties Air Basin). It has a compact local rulebook — Regulations I–IX — focused on general permit requirements, visible emissions, open burning, gasoline vapor recovery, and toxics. It does **not** have dedicated local rules for architectural coatings, solvents/VOCs, graphic arts, or industrial surface coating. Those source categories are governed by CARB statewide rules and Title 17 CCR.

## One-Line Decision Guide

**Does this project need an ATC/PTO?**

1. **No permit needed** if the equipment falls into Rule 402's exempt categories: residential (≤2-family) equipment; comfort HVAC not on process exhaust; refrigeration (non-pollution-control); natural gas/LPG boilers <50 MMBtu/hr; IC engines fired on nat-gas/LPG of any size, or diesel/gasoline engines ≤1,000 cu-in displacement; lab equipment; welding/brazing; steam cleaning; food-prep equipment; natural gas compression; mobile construction equipment; implements of husbandry; maintenance (no structural changes); sources emitting <1 ton/yr of any criteria pollutant.

2. **ATC then PTO required** for any other new, altered, or replaced stationary emission source.

3. **Retail gas stations:** New stations require an ATC before construction and must install ARB-certified Phase I (tank delivery) and Phase II (vehicle fueling) vapor recovery systems. Existing stations with throughput ≤480,000 gal/yr are exempt until throughput threshold is crossed or tank replacement occurs.

4. **No local coating/solvent/graphic-arts rule:** Projects involving architectural coatings, VOC solvents, or printing inks are governed solely by CARB statewide rules — no separate Mariposa APCD permit is triggered by those activities alone (unless another emission threshold is crossed).

## Key Numeric Thresholds

| Parameter | Threshold | Rule |
|---|---|---|
| Major Facility | ≥100 tons/yr OR ≥1,000 lb/day of any criteria pollutant | Rule 102 |
| Major Modification | Increases actual/PTE by ≥100 tons/yr OR ≥1,000 lb/day | Rule 102 |
| De minimis ATC exemption | <1 ton/yr of any criteria pollutant or precursor | Rule 402 (catch-all) |
| Boiler ATC exemption | Natural gas/LPG heat input <50 MMBtu/hr | Rule 402E |
| IC engine ATC exemption | Nat-gas/LPG any size; diesel/gasoline ≤1,000 cu-in displacement | Rule 402C.3 |
| Visible emissions limit | Ringelmann 1 (20% opacity), >3 min/hr | Rule 202 |
| Particulate matter | 0.1 gr/dscf (process sources) | Rule 207 |
| Sulfur dioxide | 2,000 ppm (0.2%) in exhaust gas | Rule 210A |
| Combustion contaminants | 0.1 gr/dscf (all sources); 0.2 gr/dscf (wood boilers) | Rule 210B |
| Steam generator SO2 cap | 200 lb/hr | Rule 209A |
| Steam generator NOx cap | 140 lb/hr | Rule 209B |
| Gas station throughput exemption | ≤480,000 gal/yr (existing stations) | Rule 900 |
| Gas storage tank Phase I exemption | <260 gallons (1.0 m³) capacity | Rule 900 |

## What This District Does NOT Have

- No architectural coatings rule (use CARB Reg. for Reducing VOC Emissions from Architectural Coatings)
- No VOC/solvent use rule
- No graphic arts / printing rule
- No wood products / furniture coating rule
- No degreasing rule
- No NOx RACT rules for non-major sources
- No RECLAIM or cap-and-trade program

All of the above categories are regulated at the state level only for sources in this district.
