# Federal EHS regulatory reference (NOT active skills)

The project scope is **California-only** right now. These federal-domain notes
were researched for future multi-jurisdiction expansion and are kept as
reference, NOT wired as active `src/lib/research/skills/`. Do not load these as
skills until the scope expands beyond California.

Domains researched (verified against eCFR/EPA/OSHA primary sources):
- RCRA hazardous waste (40 CFR 260-279): VSQG/SQG/LQG generator thresholds.
- Federal Clean Air Act: Title V (100 tpy), PSD/NSR (100/250 tpy), NESHAP/MACT (10/25 tpy HAP).
- EPCRA: Tier II (10,000 lb / 500 lb-or-TPQ), TRI (25,000/10,000 lb), 302/304.
- OSHA PSM (29 CFR 1910.119): 10,000 lb flammable + Appendix A TQs.
- SPCC (40 CFR 112): 1,320 gal aboveground / 42,000 gal buried.
